# GarageOS service-provider / subprocessor register

Internal register. Last full review: **2026-09-30**. Re-review at least every 6 months and whenever a provider, region, data category or feature changes (see ENGINEERING-RULES.md).
Do not publish location claims from this document until the "not verified" items are closed and legal review is done.

**Evidence levels used below**
- **INFRA** = read directly from our connected Vercel/Supabase accounts/repo on 2026-09-30.
- **DOC** = stated in the provider's official documentation. In this review the provider pages were reached through search-result summaries (and, for Supabase, the Supabase docs API); the primary page was not opened in a browser. Re-open the linked page before relying on a DOC fact contractually.
- **NV** = not verified. Never treat as fact.

GarageOS role: for shop-staff accounts and billing, GarageOS is the enterprise holding the information; for end-customer data entered by shops (customers, vehicles, invoices, photos, messages), GarageOS acts as the shops' service provider. The providers below are GarageOS's own service providers/subprocessors.

## Environment separation (INFRA, Vercel + repo, 2026-09-30)
**Proven, not inferred:** the Preview build of commit `d0eaddd` (branch `claude/storage-privacy-hardening`) logged the Neon datasource and ran `prisma migrate resolve`, `prisma migrate deploy` ("No pending migrations"), the sender-identity backfill (2 shops processed) and the super-admin bootstrap (`admin@garage-os.ca updated as SUPER_ADMIN`) against the **production database**, because `npm run build` calls `scripts/deploy-migrations.mjs` unconditionally and Preview shares `DATABASE_URL`. A Preview branch containing a new migration would have migrated production. **Code fix in this PR:** the script now skips all DB steps unless `VERCEL_ENV` is `production` (or unset locally); opt in for a dedicated Preview DB with `RUN_DB_STEPS_ON_PREVIEW=1`. This stops build-time writes only — **a running Preview deployment still reads/writes the production database until the Preview `DATABASE_URL` is separated.** Preview URLs are behind Vercel Authentication (INFRA).

Legend — **MUST**: before any further Preview testing · **SHOULD**: before paid launch · **OK**: safe to share. "After DB split" = once Preview has its own database.
